## Best practices

### Layout

- Place it last in the "Verdict" (studios) or "Best uses" (spots) section, spaced from the text above by the page.
- Use an alert, not a disclosure, for warnings and news such as stale prices or permits.

### Content

- Title: "How this session was paid for" for studios, "How this visit was paid for" for spots.
- The statement is a fixed, translated sentence the application chooses from the stored answer; name the studio when the session was discounted or comped.
- End with the "Editorial policy" link.

### Accessibility

- Plain content: no role and no live region; it is read in order. The title is a `<p>`, so the page outline keeps one `h2` per section.
- The icon is decorative; the only tab stop is the policy link.
