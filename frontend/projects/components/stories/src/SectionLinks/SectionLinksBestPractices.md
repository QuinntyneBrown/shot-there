## Best practices

### Layout

- Use it for the rows of the site menu sheet; each whole row is one link, tall enough for a thumb.
- Titles and meta wrap; nothing truncates at 320px.

### Content

- Titles are the section name: "Studios", "Editorial policy". No articles, no verbs.
- Meta says what is behind the link in under eight words: "Every studio and spot on one map"; admin counts follow the dashboard, "7 published, 2 draft".
- Set `attention` only when the meta states a reason in words ("2 items need re-verifying"); the colour never carries the meaning alone.

### Accessibility

- A row's name is its title and meta together ("Studios 7 rental studios, measured the same way"), so keep the meta short.
- `navLabel` names the landmark ("Primary", "Administration").
