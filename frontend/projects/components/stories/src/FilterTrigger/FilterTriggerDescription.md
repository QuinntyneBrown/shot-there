The DS filters trigger: the pill-shaped "Filters" button that opens the filters sheet on the studio and spot lists below LG. `st-filter-trigger` is an attribute on a native `<button>` or `<a>`; the host carries `.filter-trigger` and `aria-haspopup="dialog"`, and renders the filters icon before the default slot.

Above 0, `count` adds the `.filter-trigger__count` bubble. The number in it is hidden from assistive technology and a hidden ", 2 active" follows, so the name reads "Filters, 2 active".
