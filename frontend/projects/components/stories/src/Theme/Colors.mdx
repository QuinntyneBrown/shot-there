# Colors

A white canvas, near-black ink and one warm red accent for "selected / you are here". Photos, prices, scores and
measurements do the talking, so the interface stays quiet.

Every swatch on this page is read from `styles/tokens.css` and painted with its live custom property — switch the
**Theme** toolbar to Dark to see the dark values. Components read the semantic `--color-*` roles, never a `--palette-*`
primitive and never a hex value.
