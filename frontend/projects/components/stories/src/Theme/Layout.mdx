# Layout

Phone first. The viewport classes are XS below 36rem, SM 36rem, MD 48rem, LG 62rem and XL 75rem; content stops
growing at 90rem. Columns, gutter, margin and the top bar height step up at MD and LG (and the margin again at XL).
Media queries cannot read custom properties, so components repeat the breakpoint values literally — and only these
values. Use the **Viewport** toolbar to preview each class.
