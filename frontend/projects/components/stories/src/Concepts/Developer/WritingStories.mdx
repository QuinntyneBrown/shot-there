# Writing stories

Stories follow the Saturdaze / Fluent UI docsite layout: one folder per component under
`frontend/projects/components/stories/src/`, with small, copy-pasteable story files.

```text
stories/src/Button/
├── index.stories.ts           # meta (title, component, imports) + re-exports
├── ButtonDescription.md       # what it is, which DS classes it carries
├── ButtonBestPractices.md     # ## Best practices — Layout / Content / Accessibility
├── ButtonDefault.stories.ts   # `Default` — args wired to inputs for Controls
├── ButtonVariant.stories.ts
└── ButtonSize.stories.ts
```

Only `index.stories.ts` is globbed by `.storybook/main.ts`; it owns the meta and re-exports each story:

```ts
import type { Meta } from '@storybook/angular';
import { moduleMetadata } from '@storybook/angular';
import { ButtonComponent, IconComponent } from '@shot-there/components';

import descriptionMd from './ButtonDescription.md';
import bestPracticesMd from './ButtonBestPractices.md';

export { Default } from './ButtonDefault.stories';
export { Variant } from './ButtonVariant.stories';

export default {
  title: 'Components/Button',
  component: ButtonComponent,
  decorators: [moduleMetadata({ imports: [ButtonComponent, IconComponent] })],
  parameters: {
    docs: { description: { component: [descriptionMd, bestPracticesMd].join('\n') } },
  },
} as Meta<ButtonComponent>;
```

Each story file exports one `StoryObj` with a template and a short description:

```ts
export const Variant: StoryObj<ButtonComponent> = {
  render: () => ({
    template: `<button st-button variant="ghost" type="button">Cancel</button>`,
  }),
  parameters: {
    docs: { description: { story: '`ghost` is for low-emphasis actions.' } },
  },
};
```

## Checklist

- `Default` comes first and binds `args` to inputs so Controls work.
- Use realistic ShotThere copy — real Toronto studios and spots, prices in CAD — not "Lorem ipsum".
- Inputs, outputs and their JSDoc come from compodoc — document them on the component, not in the story.
- New component? Export it from `src/public-api.ts`, then add its story folder.
