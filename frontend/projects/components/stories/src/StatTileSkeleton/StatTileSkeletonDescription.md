The loading placeholder for a stat tile: `li[st-stat-tile-skeleton]` keeps the tile's card box (`.stat-tile .stat-tile--skeleton`) and draws three `st-skeleton` placeholders — a title bar, a 70 % counts bar and an 8rem pill where the action goes.

It has no inputs and is `aria-hidden="true"`; the page's status message carries the meaning while it shows.
