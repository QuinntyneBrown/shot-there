The DS button. `st-button` is an attribute on a native `<button>` or `<a>`, so `type`, `disabled`, `href` and `routerLink` stay the consumer's. The host carries the `.btn` classes from the design system (`.btn--primary`, `.btn--sm`, `.btn--icon`, …).

The default slot is the accessible name, with an optional `st-icon` before or after it.
