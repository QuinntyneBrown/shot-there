The DS system page for not found and server errors. The `st-error-page` host is the centred `.system-page` block: an optional `code` line, the page's `h1` from `title`, optional `text`, the default slot for a paragraph (such as one with a mail link), an optional `reference`, and the actions.

Actions are links with `slot="actions"`. The component renders the page's only `h1`, inside the application's `main`, header and footer.
