Responsive

Below 48rem every chip is 44 px tall with 44 × 44 px remove buttons; from 48rem chips are 36 px with 24 px remove buttons. The row wraps and Clear all wraps with it. Each frame is a real viewport and shows the results header as the application lays it out.
