Responsive

The skeleton itself does not change by breakpoint; it reflows with the containers it sits in (one card column below 36rem, two from 36rem; the admin table stacks below 48rem). Each frame is a real viewport.

Contrast

Skeletons carry no information, so they have no contrast requirement (WCAG 1.4.11 does not apply); the region's status text carries the meaning and is checked by its own component.
