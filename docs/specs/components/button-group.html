Map

12 locations

The map bar (pages/map/default) as it renders below 62rem: "Show" with "Both" pressed and "View as" with "Map" pressed; every item is a button type="button" with aria-pressed and data-text. The bar's visually hidden status reads "12 locations". AC-1, AC-2
pages/map/studios-only: "Studios" pressed after the visitor pressed it (or the application set value to "studios"); the count reads "7 locations". AC-3, AC-6
Pressing the pressed item again: nothing changes and no valueChange is emitted. AC-4
pages/map/list: "List" pressed; the map is hidden and focus stays on "List". AC-5
value matching no option (the default ''): nothing pressed (D-5). Never seen on a real screen.

Sizes

One size: --text-body in a 44 px target, --space-5 between words; width is the word. AC-10

States

Hover, focus and active are forced with data-state (documentation only); pressed uses the real aria-pressed. There are no disabled or link items (D-2, D-3).
