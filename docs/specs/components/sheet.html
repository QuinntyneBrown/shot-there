Responsive

Below 48rem the sheet fills the viewport and rises from the bottom; from 48rem it is a 28rem side sheet over the dimmed page (D-3). Each frame is a real viewport. Safe-area insets are zero in a desktop browser; the padding rules that add them are in the CSS.
