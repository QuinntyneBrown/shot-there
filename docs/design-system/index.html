ShotThere design system

Tokens, components and patterns for ShotThere, the first-hand review and comparison site for places to shoot photos in Toronto. Extracted from the 143 ShotThere mocks: white space, one ink button per screen, accent red only for “selected”, and numbers you can compare at a glance.

Start here

ShotThere reviews rental studios, then outdoor spots, with the same measurements and test setup every time, so locations compare side by side. The interface stays out of the way of that evidence: a white canvas, a quiet text nav, photos at their real proportions, and prices, scores and measurements set in tabular figures. Three rules hold everywhere:

  • One ink primary button per screen (--color-action).
  • Accent red means “selected” or “you are here” (--color-accent): a pressed Compare toggle, an active filter, the current nav item. It is never an action and never an error.
  • Never colour alone: scores are a number plus pips, map markers differ by shape, statuses are a word plus a shape.

How to use

  1. Link the CSS in this order: tokens/tokens.css (every value, both themes), then assets/components.css (every component class). assets/ds.css and assets/ds.js are only for these documentation pages.
  2. Use the classes and attributes from each component's Code section. State lives in real attributes (disabled, aria-pressed, aria-current, aria-invalid, aria-expanded, aria-busy); data-state only forces hover, focus and active in these static pages. The mocks, the Angular frontend and its Playwright page objects share these class names.
  3. Read tokens by role, never by value. Use var(--color-fg-muted), not the hex. Platforms that cannot read CSS consume tokens/tokens.json (W3C DTCG format; aliases preserved; dark overrides under $extensions).
  4. Theme with data-theme="light|dark" on <html>; with no attribute the OS preference applies. Press t on any page here to flip it.
  5. Check before shipping a change: check_contrast.py on tokens.css must pass in both themes, and check_design_system.py on this folder must report 0 errors (see README.md for the commands and the last run).
