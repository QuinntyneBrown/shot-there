Checkbox

Checkboxes let people pick any number of options: the neighbourhoods and gear in the studio filters, the spot types and uses in the spot filters, a spot's best uses in the editor. A single checkbox records one yes-or-no fact, like "20 A circuits available".

Overview

A checkbox is a <label class="choice"> wrapping a native checkbox and its text, so the whole row is the target. Use it:

  • In a group, inside a <fieldset> whose <legend> asks the question, when any number of answers can apply. Within a filter, ticked values combine with OR: Junction or Leslieville (L2-022.2).
  • On its own, for one fact that is either true or not: "20 A circuits available" in the studio editor, "Cyc wall" in the studio filters.

When exactly one answer applies, use a radio group (parking, permit, disclosure). In the filters, each group is a filter group and changes apply when the visitor shows the results, never on each tick.

Anatomy

  1. Box20px (--icon-size-md), --radius-xs, 1px --color-border-strong edge on --color-bg-surface. Checked fills --color-accent with a tick in --color-fg-on-accent.
  2. LabelThe option in --text-body, 12px (--space-3) after the box, top-aligned so long labels wrap under themselves.
  3. Description (optional)small inside .choice__text, --color-fg-muted: the rule behind the option.
  4. RowThe label.choice: the whole row toggles the box. At least 24px tall (--target-min), 44px below 48rem.

"Natural light" in the studio filters (dialogs/studio-filters/selected).

Sizes

One size: a 20px box beside 16px text. The row, not the box, is the touch target, so a bigger box adds nothing; density comes from the list, never from a smaller box.

States

Hover and focus are forced with data-state; checked, disabled and invalid use checked, disabled and aria-invalid. Indeterminate is a DOM property with no attribute, so this page draws it with data-state="indeterminate". No mock shows a disabled, invalid or indeterminate checkbox; those rows are ready for when one is needed. Pressing (active) shows nothing extra.

Responsive behaviour

  • Below LG the studio and spot filters open in a full-height sheet; from LG they sit in a sidebar beside the list (L2-022.5). The checkbox rows are the same in both, one per line.
  • Below 48rem every .choice row is at least 44px tall (L2-065.3); from 48rem, 24px, so the sidebar's seven neighbourhoods fit without scrolling.
  • Long labels ("No permit needed for the selected use") wrap under themselves, never under the box.

Theming

The box reads semantic tokens: --color-bg-surface and --color-border-strong unchecked, --color-accent fill and --color-fg-on-accent tick when checked, --color-danger-solid for the invalid double edge. In dark the accent moves to its lighter step and the tick turns dark, keeping 4.5:1 inside the box. In forced colours the checked box takes Highlight.

Accessibility

Role and pattern

Native checkbox (WAI-ARIA APG checkbox pattern) inside a wrapping label; groups use <fieldset> and <legend> so each box is heard with its question: "Included gear, group. Lights, checkbox, not checked".

Keyboard

KeyAction
Tab / Shift+TabMoves to the next or previous box; every checkbox is its own tab stop.
SpaceTicks or unticks the focused box.
EnterDoes nothing in the filters sheet (results show from the footer button); in the sidebar form it submits the filters.

Focus

The shared ring draws around the box with its offset, 2px at 3:1 or more against the page and the sheet (L2-067.2). Ticking never moves focus.

Labelling

The text in the wrapping label is the name; a description in small is part of it ("Natural light At least medium at some time of day"), so keep descriptions short. The legend names the group; the filter sidebar's legends use .filter-group__title but stay real legends.

Motion

Fill and edge colour transition over --duration-fast; reduced motion zeroes it. The tick appears at once.

Touch

The whole row is the target: 44px tall below 48rem and at least 24px above (L2-065.2–3). The 20px box alone is never the only target.

Content

  • Labels are the option's name in sentence case, matching the public page: "Kensington Market", "Indoor public", "Cyc wall".
  • A single checkbox states the positive fact: "20 A circuits available", never "No 20 A circuits".
  • When the option hides a rule, the description says it: "At least medium at some time of day".
  • Order by what people scan for: neighbourhoods alphabetically, gear in the order the review lists it (Lights, Modifiers, Stands, Backdrops), uses as the spot pages list them.
  • Legends are nouns or short questions: "Neighbourhood", "Included gear", "Best for".
