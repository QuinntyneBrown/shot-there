Button group

A short row of toggle buttons where exactly one is on. On ShotThere it is the map's "Show" control (Both, Studios, Spots) and its phone "View as" toggle (Map, List), drawn as a quiet segmented row.

Overview

Use a group when two or three short, mutually exclusive options change what the current page shows, and the change is instant.

  • Segmented control (.segmented) is the one ShotThere uses: a wrapping row of words, muted at rest, accent and semibold when pressed. The map bar has two: "Show" filters the markers and list by type (L2-027.2), and "View as" swaps the map and the list below 62rem (L2-029). Changing either updates the polite count in the bar ("12 locations", "7 locations").
  • Button group (.btn-group) joins outlined buttons into one pill; the pressed segment takes the accent tint. The CSS is kept, but no ShotThere mock uses it yet. It is shown below with the map's "View as" choice so the two looks can be compared; prefer .segmented until a screen needs a joined control.

Not a button group: sort is a select labelled "Sort by" with "Most recent review", "All-in cost, low to high" and "Overall score, high to low" (L2-023); filters are checkboxes and radios in the filter panel (filters); a single on/off action such as "Add to compare" is the compare toggle.

Anatomy

  1. Group.segmented with role="group" and an aria-label naming the choice ("Show", "View as"). A wrapping flex row with --space-5 between items.
  2. Pressed itemaria-pressed="true": --color-fg-accent and semibold, so it doesn't rely on colour alone. Exactly one per group.
  3. ItemA borderless <button> in muted body text, 44px tall (--target-comfortable). data-text repeats the label so its semibold width is reserved.

Sizes

One size each. Segmented items are body text (--text-body) in a 44px target with --space-5 between them. Button-group segments are medium buttons, 44px tall. Neither changes size by breakpoint.

Both 44px tall; the segmented row is about half the width.

States

Hover, focus and active are forced with data-state; pressed and disabled use aria-pressed and disabled.

Both themes

  • Pressed is always exactly one. Pressing the pressed item again does nothing; it does not unpress. "Both" and "Map" are pressed on first load.
  • Loading is not a state of the control. While markers load, the list keeps aria-busy="true" and the bar's status reads "Loading locations…"; the control stays usable (pages/map/loading).
  • Disabled has CSS (--color-fg-disabled) but no ShotThere mock uses it. A type with no locations stays enabled and leads to the map's empty state ("No locations yet.").

Responsive behaviour

  • Below 62rem the map bar holds the title, "Show" and "View as"; it wraps (flex-wrap, --space-4 apart), so at 360px "Show" and "View as" drop under the title. The map fills the remaining viewport height (L2-029.1).
  • From 62rem (LG) "View as" is hidden by .map-page__toggle: list and map sit side by side without a toggle (L2-029.3). "Show" stays.
  • Segmented rows wrap and never scroll sideways. Below 48rem wrapped lines sit 8px apart (row-gap: var(--space-2)).
  • A button group stays joined from 48rem; below it the segments become separate pills 8px apart, so each keeps its own 44px target and visible edge. Keep a group to three segments of one word.

Theming

The segmented control reads --color-fg-muted at rest, --color-fg-default on hover, --color-fg-accent and --font-weight-semibold when pressed, and --color-fg-disabled when disabled. The button group reads the button tokens, plus --color-accent-subtle, --color-accent and --color-fg-accent for the pressed segment. In dark the accent becomes a light accent red on a deep tint; in forced colours the pressed segmented item is underlined so the state survives the loss of colour.

Accessibility

Role and pattern

A role="group" with an aria-label, holding native toggle buttons with aria-pressed (APG Button, toggle). Each button is its own tab stop, which suits two or three items better than a radio group's arrow keys.

Keyboard

KeyAction
Tab / Shift+TabMoves between items, then on to the next group or the list.
Enter, SpacePresses the item; the one that was pressed is released. Focus stays on the item.

Focus

The shared ring draws round the word. Switching "View as" to "List" hides the map but leaves focus on "List", so keyboard users stay oriented.

Labelling

The group label says what is being chosen ("Show", "View as"); each button's text is its name and screen readers add "pressed" or "not pressed". The result is announced by the bar's polite status ("7 locations"), not by the buttons.

Pressed is carried by weight as well as colour (semibold), and by an underline in forced colours.

Motion

Only the text colour transitions, over --duration-fast; reduced motion zeroes it. The view change itself is instant.

Touch

Every item is 44px tall (L2-065.3), and --space-5 (20px) separates neighbouring words, so the targets don't crowd.

Content

  • One word per item, sentence case, the noun the page uses: "Both", "Studios", "Spots", "Map", "List".
  • The group label is short and reads before every item: "Show", "View as".
  • Broadest option first and pressed by default: "Both" before "Studios" and "Spots"; "Map" before "List".
  • No counts in the items. The result count lives once, in the bar's status line.
