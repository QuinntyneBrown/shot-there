Disclosure

The disclosure is a quiet, fixed callout at the end of every verdict that says how the session was paid for: paid in full, discounted by a named studio, or comped by a named studio. It looks the same whatever the answer, so no review can be read as more or less trustworthy from its styling.

Overview

Every review page must disclose whether the session was paid for or comped (L1-011). Each location stores one of three values, paid_in_full, discounted or comped, with the provider's name for the last two (L2-045), and a location can't be published without it. The disclosure turns that value into one fixed sentence.

  • Where: always in the same place. On a studio it is the last thing in the "Verdict" section, after "Who it's for" and "Who should skip it" (L2-012). On a spot it is the last thing in "Best uses" (L2-020.3).
  • How: one callout per review, never repeated, never moved into the summary panel, the footer or a collapsed section.
  • Not for: warnings or news. Stale prices and permits use a warning alert; the disclosure is a fact about the review, not about the location.

Anatomy

  1. ContainerFlex row on --color-bg-surface-sunken with a 2px --color-border-strong rule on the left; --space-4 × --space-5 padding; square left corners, --radius-md on the right.
  2. IconThe information glyph, 20px, --color-fg-muted, aria-hidden; nudged down --space-0-5 to sit on the title's first line.
  3. Title .disclosure__title"How this session was paid for" (studio) or "How this visit was paid for" (spot), --text-label at 16px.
  4. StatementThe fixed sentence for the stored value, in body text; the paragraph runs the full width of the callout (max-width: none).
  5. Policy link"Editorial policy", an inline link at the end of the statement, to the page that defines all three sentences.

Variants

The variants are the stored values. The container, icon and order never change; only the sentence does.

Sizes

One size. It fills the width of the section it ends, in the main column of the review layout.

States

The callout itself doesn't react; its one control is the "Editorial policy" link. There is no empty state: a location without a disclosure value can't be published (L2-045.3), and a discounted or comped value without a provider can't be saved (L2-045.1).

Responsive behaviour

  • The same at every breakpoint: the callout fills its column, the icon stays at the top left, and the title and statement wrap beside it. Padding doesn't change.
  • XS to MD: the column is the full page width less the page margins; the statement runs to three or four lines at 360px.
  • LG and up: the main column beside the summary panel; the statement fits in one or two lines.
  • Long provider names wrap between words like any other text; nothing truncates.

Theming

Neutral on purpose. The callout reads --color-bg-surface-sunken, --color-border-strong for the rule, --color-fg-muted for the icon and --color-fg-default for the text, and no tone family: it is never accent red, warning amber or success green, whatever the value. A comped session is information, not a warning; paid in full is not an achievement.

In dark the well steps up to stone-900 on the stone-950 canvas and the rule stays stone-500, so the callout still reads as set apart. No component tokens; re-theme through the semantic tokens.

Accessibility

Role and pattern

Plain content: a <div> holding two paragraphs, no ARIA role and no live region. It is read in reading order at the end of the "Verdict" or "Best uses" region, which is where a screen reader user finishes the verdict, so it is found by the same route as everything else. It is not a heading: the title is a <p>, so the page outline stays one <h2> per section.

Keyboard

KeyAction
TabStops once, on "Editorial policy".
EnterOpens the editorial policy in the same tab.

Focus

Never moves. The link takes the shared 2px focus ring with a 2px offset, drawn on the sunken well.

Labelling

  • Read as: "How this session was paid for. This session was discounted by Leslieville Daylight Studio. That did not affect the scores. Editorial policy, link."
  • The icon is decorative (aria-hidden="true"); the title carries the meaning.
  • "Editorial policy" makes sense out of context in a links list (2.4.4).
  • The provider's name is plain text, not a link to the studio, so the disclosure can't be read as an endorsement.

Contrast

Title and statement
Icon
Left rule

The policy link (--color-fg-link, and --color-fg-link-hover on hover) and the focus ring sit on --color-bg-surface-sunken; those three pairs are checked in contrast-pairs.json. The link is also underlined, so it never relies on colour alone (1.4.1).

Motion

None.

Touch

One inline link in a sentence, exempt from the 24px target minimum (2.5.8) and given the full line height. Nothing depends on hover.

Content

The sentences are fixed, defined on the editorial policy page, and filled only with the provider's name as stored. Don't paraphrase them per review.
