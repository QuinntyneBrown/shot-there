Toast

A toast confirms an action the person just took, without moving them: "Link copied", "Corktown Garage Studio is published", "You can compare up to 4 studios". It appears at the bottom of the screen, says what happened and, at most, offers one next step.

Overview

Use a toast for the result of an action whose effect is elsewhere or not yet visible. Use an alert for a condition that stays true on the page, and an inline message for a problem with one field or image.

  • Public toasts (visitors): copying the comparison link worked or failed (L2-032), and adding a fifth studio to compare was refused (L2-030.3).
  • Admin toasts (the owner): a new studio saved with a numbered address, published, unpublished, or a save that failed (L2-054, L2-056, L2-061).

Info, success and warning toasts dismiss themselves after 8 seconds, pause while hovered or focused, and show a timer bar. A danger toast never dismisses itself and has no bar. There is no Undo: reversing a publish is Unpublish, which asks for confirmation.

Anatomy

  1. Tone iconCircle i, tick, triangle or circle !; aria-hidden, in the text colour, so the shape carries the tone on the inverse surface.
  2. Title.toast__title: what happened, naming the thing.
  3. Text.toast__text: one sentence of consequence or next step, at 90% opacity.
  4. Action (optional).toast__action: one underlined link or button, "View public page" or "Try again".
  5. Dismiss.close with aria-label="Dismiss"; 24 × 24 from 36rem, 44 × 44 on phones.
  6. Timer bar.toast__progress, aria-hidden: a thick line along the bottom for toasts that dismiss themselves.

Variants

All tones share the inverse surface; the modifier picks the icon and the live role, not a colour.

Sizes

One size: 24rem wide from 36rem, the screen width minus 16px each side below it. Height follows the text.

States

The toast's controls have the usual states, forced here with data-state; on the inverse surface the focus ring takes --color-fg-inverse. Hovering or focusing anywhere in a toast pauses its timer; that has no visual change beyond the bar stopping.

  • The region ignores pointer events and each toast takes them back, so the page under the gap stays clickable.
  • Text wraps; long addresses such as /studios/annex-attic-studio-2 break anywhere.
  • Toasts are hidden in print.

Theming

Every toast uses the inverse pair, --color-bg-inverse and --color-fg-inverse: a near-black toast on the light theme, a near-white one on the dark theme, so it stands off either page. Icons take the text colour rather than a tone colour, because tone colours on the inverse surface do not keep 3:1 in both themes; the icon shape carries the tone. In forced colours the fill becomes Canvas and a 1px CanvasText edge outlines the toast.

Accessibility

Role and pattern

WAI-ARIA APG Alert pattern and WCAG 4.1.3 Status Messages. The .toast-region is in the page from the start as role="status" aria-live="polite"; info, success and warning toasts are inserted into it and read politely. A danger toast carries role="alert" and is read at once. Test with NVDA and VoiceOver: if a danger toast is read twice because it sits inside the polite region, render danger toasts into a sibling role="alert" container in the same stack.

Keyboard

KeyAction
TabReaches the action and Dismiss in DOM order, after the content the region follows. Focus inside pauses the timer.
Enter / SpaceActivates Try again or Dismiss; Enter follows View public page.
EscNo global binding; Esc belongs to open dialogs.

Focus

A toast never takes focus. After Compare on a fifth studio, focus stays on that Compare button (L2-030.3); after Publish it stays in the editor. When a focused toast is dismissed, focus returns to the control that raised it.

Labelling

The title names the studio or the link so the announcement stands alone ("Couldn't save Corktown Garage Studio"). Dismiss is aria-label="Dismiss"; icons and the timer bar are aria-hidden.

Contrast

Text, icon and focus ring on the toast
Toast edge (decorative)

.toast__text is drawn at 90% opacity; blended at that opacity it still measures about 15:1 in the light theme and 13:1 in the dark. The timer bar is decorative.

Motion

Enter and leave animate over --duration-base; under prefers-reduced-motion the token drops to 0.01ms, so toasts appear and go without movement. Timers are long enough to read two lines (8 s) and pause on hover and focus.

Touch

Dismiss and the action are 44px tall below 36rem (L2-065.1), with 16px between the action and the next line.

Content

  • Title says what happened, past tense or a state, naming the thing: "Corktown Garage Studio is published", "Link copied".
  • Failures start "Couldn't …" and the text says what is safe and what to do: "Your changes are still here. Check your connection and try again."
  • Refusals state the limit and the way out: "You can compare up to 4 studios" · "Remove one from the bar to add Ossington Blackbox."
  • The text is one sentence; it may name timing ("within a minute").
  • One action, as a verb phrase: "View public page", "Try again". No "OK", no Undo.

Drift found during extraction:

  • public-toast/warning raises the region with an inline style="bottom: calc(var(--space-24) + env(safe-area-inset-bottom))". Documented as "above the compare bar"; .has-compare-bar .toast-region now does it whenever the page carries the bar, so the inline style can go.
  • public-toast/warning draws the triangle as M12 3 2 20h20L12 3z; the admin toasts use M12 4 2.5 20h19L12 4z. Documented with the admin path.
  • Danger toasts nest role="alert" inside the polite role="status" region in every mock; kept, with the double-announcement test noted under Accessibility.
  • .toast__progress has a fixed 60% width in the stylesheet; the countdown animation is left to the script.
