Container

The layout every ShotThere screen is built from: one centred container, stack and cluster for rhythm, and a small set of page layouts for the studio and spot lists, the home page, sign-in, reviews, editors and the map.

Overview

Layout classes carry no colour and no meaning; they only place things. The gaps come from tokens that grow with the screen, so a page built from these classes reflows from 320px to a wide desktop without sideways scrolling (L2-069.3). Reach for them before writing a one-off margin.

  • Primitives: .container wraps every page's main, the site header and the footer; .container--narrow caps reading pages at 42rem. .stack spaces children top to bottom, .cluster lays them in a wrapping row, .prose sets long text and .section-gap separates the big blocks of a page.
  • Page layouts: .browse (studio and spot lists, with the filter sidebar from 62rem), .page-header (the h1 block of every other page), .home-hero, .section-head (a section title with its "All studios" link), .has-compare-bar (room for the fixed compare bar), and .auth (owner sign-in).
  • Layouts with their own page: review layout (.review-layout, studio and spot reviews with the summary panel), editor layout (.editor-layout, the admin editors with the status aside) and the map page (.map-page, list beside map).

For the studio and spot card grid see location card; for the filter sidebar's content see filters. The spacing values themselves live in Spacing and Layout.

Anatomy

  1. Page header.page-header holds the page's one h1 and a muted .subtitle line; --space-6 above and below.
  2. Page actionThe screen's one primary ("New studio") sits at the end of the header row and wraps under the title when there is no room.
  3. Margin--layout-margin inside .container: 16px, 32px from 48rem, 48px from 62rem, 80px from 75rem.
  4. Column--layout-columns: 4, then 8 from 48rem, then 12 from 62rem.
  5. Gutter--layout-gutter: 24px, 32px from 48rem, 40px from 62rem.

  • Every column uses minmax(0, 1fr) and grid cells wrap long words, so a long studio name or a booking URL wraps instead of forcing sideways scroll.
  • The site header, main and footer all use .container, so their edges line up at every width.
  • Sticky children (the summary panel, the editor aside) sit --space-8 from the top and never cover focused content; scroll-padding-top equals the header height.

Theming

Layouts read no colour tokens; the page canvas comes from body. They read the layout tokens (--layout-*) and the spacing scale, which are identical in light and dark. Themes never change layout. To make one area denser, override a layout token on a wrapper (a tighter --layout-gutter) rather than adding margins to the children.

Accessibility

Role and pattern

Layouts are built on landmarks (APG Landmark regions): header, main id="main" tabindex="-1" (the skip-link target), aside aria-labelledby="filters-title" for the filter sidebar, section aria-labelledby for the results and each home section, the compare bar as aside aria-label="Studios to compare", and footer. One h1 per page, in .page-header, .browse__title, .home-hero, .auth__head or the review head.

Keyboard

KeyAction
Tab (first press)Shows "Skip to main content", which jumps past the header into main (L2-067).
Tab / Shift+TabFollows source order, which is visual order at every width. .browse places the sidebar with grid-template-areas but keeps it after the title and before the results in the source.

Focus

Layouts never clip focus rings: containers do not set overflow: hidden. The fixed compare bar does not cover the focused card because .has-compare-bar reserves its height (WCAG 2.4.11).

Labelling

Repeated landmarks have names: the sidebar is labelled by its "Filter studios" heading, the results by a visually hidden "Results" h2, each home section by its visible heading.

Motion

Layouts do not animate. Smooth scrolling to anchors is turned off under reduced motion.

Touch

At 320px with 16px margins the content box is 288px; every layout fits it without sideways scrolling, and at 400% zoom on a 1280px window the phone layout takes over (WCAG 1.4.10, L2-069.3). Fixed bottom elements add env(safe-area-inset-bottom).

Content

  • The h1 names the place or the task: "Studios", "Outdoor spots", "Compare 3 studios", "Sign in". A studio, spot or guide name is the h1 on its own page and in its editor.
  • The subtitle is one muted line of fact: "9 studios · 7 published · 2 draft", "Signed in as owner@shotthere.ca", "Last updated 1 October 2026". No welcome messages.
  • Section-head links say where they go: "All studios", "All guides", "All spots", never "See more".
  • Prose stays within --layout-measure and uses Canadian English.
  • Leave space empty. A gap is not a slot for a tip, a banner or a promotion; ShotThere has no sponsors.
