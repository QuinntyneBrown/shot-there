List rows

Rows stack short, same-shaped items with a title, one line of detail and at most a trailing value or action: the studios to retreat to when it rains, the prices and permits that need re-verifying, and the sections in the site menu.

Overview

Three row families share one shape (body on the left, title over meta, something optional on the right) and differ in what can be pressed.

  • List row (.list / .list__item): a compact read-only row whose title may be a link, with a trailing value. The spot page's rain backup list is the reference: three studios, their neighbourhood and all-in cost, and the distance.
  • Admin row (.admin-list / .admin-row): a roomier row with a status badge in the title and its own actions. The dashboard's "Needs re-verification" and "Due soon" groups use it (L2-044).
  • Section link (.section-list / .section-link): the whole row is one link, tall enough to hit with a thumb. The site menu sheet uses it for the public sections and for the admin sections (L2-064).

Use a table instead when items share three or more comparable columns: the admin studio, spot and guide lists are stacked tables, not rows. Use location cards when the photo matters, and a description list for label and value pairs about one thing.

Anatomy

  1. Title__title: the location or section name. --text-body-lg medium in admin rows and section links; --text-label at --font-size-md in list rows.
  2. Status (admin rows)A badge inside the title: "Stale" (warning) or "Due soon" (info).
  3. Meta__meta: one line of detail, --text-body-sm in --color-fg-muted. Dates are <time>.
  4. Trailing slotList rows: a value such as "3.1 km" in .num. Admin rows: __actions, small buttons pushed right. Section links: nothing; the row is the target.
  5. Hairline1px --color-border-default under each row; admin and section lists add one on top of the first row.

Responsive behaviour

  • Admin rows wrap. The body has a 128px flex basis (--space-32); when the title, badge and meta need more than what is left beside the actions, the actions drop below and stay right-aligned (margin-left: auto). The re-verification list never scrolls sideways at 320px (L2-053.3).
  • Titles wrap (overflow-wrap: anywhere in admin rows); the badge follows the name onto the next line rather than overlapping it. Nothing truncates.
  • Phone targets. Below 48rem the small Edit button grows to 44px (L2-065.1).
  • Section links only appear in the menu sheet below 48rem, where they replace the inline header links (L2-064.2). From 48rem the site header shows the same sections inline.
  • The trailing value in a list row (.num) never wraps under the title; the body shrinks (min-width: 0) and the meta wraps instead.

Theming

Rows have no fill of their own: they read the surface they sit on (the page canvas on the dashboard and spot page, --color-bg-surface-raised in the menu sheet). Hairlines use --color-border-default, meta uses --color-fg-muted. Hover uses --color-bg-surface-sunken for section links, selected uses --color-accent-subtle, and attention meta uses --color-danger-fg. Every one of these is a role that the dark theme redefines, so rows need no dark-specific CSS.

/* Section-link hover reads a role; a sheet with a different surface keeps it. */
.section-link:hover { background: var(--color-bg-surface-sunken); }

Accessibility

Role and pattern

Native lists: <ul> and <li>, announced as "list, 3 items". Links are <a href> and actions are buttons or button-styled links; no ARIA widget pattern is involved. Section lists sit inside a labelled <nav> ("Primary", "About ShotThere", "Administration"). Use the APG Listbox pattern only when rows are options to choose from, and only then use aria-selected.

Keyboard

KeyAction
Tab / Shift+TabMoves through the links and buttons in the rows, in reading order: one stop per list row title, per admin row action, per section link.
EnterFollows the focused link or activates the focused button.
SpaceActivates a <button> in an admin row; on links it scrolls the page, as browsers do.

Focus

The shared ring (2px --color-focus-ring) draws around whatever is focused: the title link, the Edit button, or the whole section link row. In the menu sheet, focus starts on Close and Tab moves down the section links; Escape closes the sheet and focus returns to Menu.

Labelling

Repeated actions carry their object in visually hidden text: "Edit Ossington Blackbox prices", "Edit Distillery District permits", so a links list does not read "Edit, Edit, Edit". A section link's name is its title and meta together ("Studios 7 published · 2 drafts"); keep the meta short. Badges are text ("Stale", "Due soon"), so status is never colour alone. Dates use <time datetime>.

Hairlines (--color-border-default) separate rows but mark no control, so they are decorative under 1.4.11. Meta on a selected row (--color-fg-muted on --color-accent-subtle) is a checked pair in contrast-pairs.json.

Motion

The section-link hover fill changes instantly; only the admin row skeleton shimmers, and that stops under prefers-reduced-motion.

Touch

Section links are at least 72px tall across the full sheet width. Admin row actions are 44px below 48rem. List row title links are text-sized, so they sit one per row with the row's padding around them.

Content

  • Title: the location's name as published ("Liberty Cyc House"), or the section name in the menu ("Studios", "Editorial policy"). No articles or verbs.
  • Meta: type or neighbourhood first, then the one fact the list is about, joined by " · ": "Studio · Prices verified 2 Mar 2026 (225 days ago)", "Riverside · All-in $100.00 for 2 hours".
  • Dates as "2 Mar 2026"; ages as "(225 days ago)", so the admin sees both the date and how stale it is.
  • Values metric with one decimal and tabular figures: "3.1 km".
  • Menu meta says what is behind the link in under eight words: "Every studio and spot on one map", "How reviews are made, paid for and corrected".
  • Actions are one verb with a hidden object: "Edit" + " Ossington Blackbox prices".
