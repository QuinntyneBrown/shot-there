Skip link

The first thing a keyboard user reaches on every ShotThere page, public or admin. It stays out of sight until it has focus, then jumps past the wordmark and the five nav links straight to the studio list, the review or the editor.

WCAG 2.2 AAStatus: stableWCAG 2.4.1 Bypass blocks · L2-067.1.skip-link

Overview

Every ShotThere page starts with <a class="skip-link" href="#main">Skip to content</a> as the first element in <body>, and has exactly one <main id="main" tabindex="-1"> (L2-067.1, L2-069.1). The link sits above the top of the viewport until it receives keyboard focus, then slides in at the top left, over the site header. Activating it moves focus to the main landmark, so the next Tab lands on the first control of the page (the filters trigger on Studios, the first editor section on the studio editor) instead of the wordmark, Studios, Spots, Map, Compare and Guides again.

  • Use it on every page template: the public list, review, map, compare and guide pages, the editorial policy, the owner sign-in, every admin screen, and the 404 and server-error pages. All 143 mocks have it.
  • Don't add a second skip link ("Skip to filters", "Skip to the map"). Landmarks and headings already let screen-reader users jump; one link is enough for sighted keyboard users.
  • Don't use it for focus management. When the site menu, the filters dialog or the lightbox opens, the dialog takes focus itself and the page behind, skip link included, becomes inert (as in dialogs/site-menu/default).

Anatomy

  1. ContainerRaised surface (--color-bg-surface-raised), --radius-md, --shadow-3, padding --space-2 --space-4, at least 44px tall; layer --z-tooltip, above the header and the compare bar.
  2. Label"Skip to content" in body text, --color-fg-default, no underline. It is the accessible name.
  3. Target<main id="main" tabindex="-1">, the page's one main landmark. It takes focus without showing a ring.

Variants

One variant. The same link, with the same label and target, is on public pages, admin pages and the sign-in page; only what it skips differs.

Skip to content

Target: #main on every page.

Shown focused. In dialog and toast mocks the link is still first in the body, inside the inert page behind the dialog.

Sizes

One size: body text with --space-2 by --space-4 padding and a 44px minimum height (--target-comfortable). It appears only on keyboard focus, so it needs no size variants.

States

The only visual change is focus: :focus-visible in the product, data-state="focus" here. It has no attribute-driven states.

Responsive behaviour

  • Identical at every breakpoint: left: var(--space-4), and top: var(--space-4) when focused. At 320px the label fits on one line with room to spare; max-width: calc(100vw - 2 * var(--space-4)) lets a longer translation wrap instead of widening the page (L2-064.1).
  • It covers the wordmark while focused; that is intended and lasts only until focus moves on. The header height (--layout-topbar-height: 4, 5 and 6rem) does not move it.
  • It stays clear of the notch: the header adds env(safe-area-inset-top) under it, and --space-4 from the top keeps the link inside the visible area in portrait and landscape (L2-065).
  • scroll-padding-top: var(--layout-topbar-height) on html keeps the target's first line from sitting under anything after the jump.
  • Touch alone never shows it, because touch does not trigger :focus-visible; a phone with a keyboard or switch access gets it as on desktop.

Theming

The skip link reads --color-bg-surface-raised, --color-fg-default and --shadow-3, like a popover, because it floats over the header. In dark the raised surface is a step lighter than the canvas and the dark --shadow-3 is stronger, so the link still separates from the header. It has no component tokens; a theme changes it through the semantic tokens only.

Accessibility

Role and pattern

A native in-page link (<a href="#main">), the standard technique for WCAG 2.4.1 Bypass Blocks. The target carries tabindex="-1" so every browser moves focus, not just the scroll position, to <main>; main[tabindex="-1"]:focus { outline: none; } keeps the landmark from showing a ring around the whole page.

Keyboard

KeyAction
Tab (first press on a page)Focuses the skip link and shows it.
EnterMoves focus to #main; the next Tab reaches the first control in the main content.
Tab again without EnterHides it and continues to the wordmark.
Shift+Tab from the wordmarkComes back to the skip link.

Focus

It must be the first focusable element: nothing comes before it in the DOM, not the toast region (which sits at the end of the body in notifications/admin-toast/success) and not the compare bar. Its own ring is the shared 2px --color-focus-ring with a 3px offset (L2-067.2).

Labelling

The visible text is the name. Don't add aria-label or title.

Contrast

Label on raised surface
Focus ring on raised surface
Focus ring on the header (canvas)

Motion

It slides down over --duration-fast (120ms) with --ease-standard. Reduced motion zeroes the duration, so it appears in place.

Touch

Not a touch feature, but it is 44px tall like every other control, so a switch or keyboard user on a phone gets a full-size target.

Content

  • Exactly "Skip to content", sentence case, on every page (L2-067.1). Not "Skip to main content", "Skip navigation" or "Jump to studios".
  • No arrows, icons or "Click here".
  • It is real copy: mark it for translation with the rest of the page.
