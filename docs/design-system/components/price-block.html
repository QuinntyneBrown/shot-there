Component · Data display

Price block

The price block opens every studio review: the all-in cost of a standard 2-hour shoot, a sentence saying how it was worked out, the hourly rate, the minimum booking and every fee marked mandatory or optional, and the date the prices were last checked, with a warning when that date is more than 183 days old.

Overview

Hourly rates don't compare: a $40.00 room with a 1-hour minimum and a $90.00 room with a 3-hour minimum cost very different amounts for the same shoot. So every studio gets one number, the all-in cost of a standard 2-hour shoot, computed by the server from the stored values (L2-004) and shown the same way everywhere:

All-in = hourly rate × the larger of 2 hours or the minimum booking + every mandatory fee

Optional fees are listed but never added. The price block is where the number is explained; the summary panel, the location card, the comparison, the rain backup list and the guides repeat the figure without the working.

Use it once per studio review, as the first section, "Pricing". Spots have no price; their permit section reuses only the verified line (.price-block__verified) under a stacking table.

Anatomy

  1. All-in figure<strong> in --text-h1 with tabular figures, CAD with two decimals: "$145.00", never "$145".
  2. WorkingOne sentence in --text-body-sm, --color-fg-muted: the hours, the rate and which fees were added.
  3. All-in panel .price-block__allinA <p> on --color-bg-surface-sunken, --radius-lg, --space-5 × --space-6 padding, --space-1 between figure and working.
  4. Rate and fees .kvA description list: hourly rate, minimum booking, then one row per fee in the order the studio lists them. "Extra fees: None" when there are none.
  5. Fee kind .badgeNeutral badge after the amount: "Mandatory" or "Optional, not in all-in".
  6. Verified line .price-block__verified"Prices verified" and a long date in <time datetime>, --text-body-sm, --color-fg-muted.
  7. Stale warning .alert--warningOnly when stale. A warning alert with role="status" after the verified line (L2-005.2).

Sizes

One size. The block fills the main column of the review layout; the all-in panel spans it, and the fee list switches from stacked to two columns at SM.

States

The price block holds no controls, so it has no hover, focus, active or disabled state; the spot verified line has one link, the source, which does. Its real states are about freshness, computed by the server from the verified date (L2-043): fresh up to 152 days, due soon from 153 to 183 days, stale from 184 days.

Price changed (editor)
You changed a price. Confirm the date you verified it.Previously 11 Oct 2026. Visitors see a warning after 183 days.

The permit date is also set explicitly by the owner (L2-042); no permit-changed mock exists yet.
  • Due soon looks exactly like fresh on public pages: Liberty Cyc House (28 Apr 2026, 168 days) shows no warning. Only the admin dashboard lists it, under "Due soon" with an info badge (L2-044.3).
  • Stale keeps every price visible and adds the warning: the alert in the price block, and the warning badge "Prices may be out of date" in the summary panel, on the list card and in the comparison cell. 183 days exactly is not stale (L2-005.3).
  • Price changed happens in the studio editor (pages/studio-editor/price-changed): editing the rate, the minimum or a fee empties "Prices last verified" and makes it required, with the previous date as help (L2-042.2). The public block changes only after saving, with the new all-in from the server and the newly confirmed date, which also clears any stale warning.

Responsive behaviour

  • XS (below 36rem): the fee list stacks, each label above its value; the badge wraps under the amount if the row is too narrow. The all-in panel keeps its padding and the working sentence wraps.
  • SM and up (36rem): the fee list becomes a 12rem label column and a value column, with hairline rules under each row.
  • LG and up: unchanged; the block sits in the main column beside the sticky summary panel, which repeats only the all-in figure.
  • The spot permit table beside the verified line stacks into one card per shoot type below MD (.table--stack, L2-015.3) and is a normal table from MD.
  • Amounts never break: "$1,250.00" stays on one line, and the working sentence breaks between words.

Theming

No component tokens. The all-in panel reads --color-bg-surface-sunken with --color-fg-default for the figure and --color-fg-muted for the working; the fee list reads the description-list tokens; the fee-kind badge reads --color-bg-subtle and --color-fg-muted; the stale alert reads the warning family (--color-warning-bg, -fg, -icon, -border).

In dark the sunken panel becomes a step lighter than the canvas (stone-900 on stone-950), so the figure still sits in a well, and the warning alert flips to a deep amber background with a light amber label. The figure is never coloured: price is a fact, not a status.

Accessibility

Role and pattern

Static content: a <p> for the all-in figure and its working, a <dl> for rate and fees (HTML description list), a <p> with <time datetime> for the verified date, and for stale prices a warning alert with role="status" (L2-005.2). It sits inside the "Pricing" <section aria-labelledby>, so it is reachable from the headings and regions lists.

Keyboard

KeyAction
TabPasses over the price block: nothing in it is focusable. On spots it stops on the permit source link.
EnterOn the source link: opens the source in a new tab.

Focus

Never moves. The source link takes the shared focus ring.

Labelling

  • Read in order: "$145.00, All-in for a standard 2-hour shoot: 2 hours at $60.00 plus the mandatory cleaning fee." The working sentence names the figure, so no extra label is needed.
  • Each fee is a term and value: "Cleaning fee, $25.00 Mandatory". The badge is text, so the fee kind is not carried by colour or shape (1.4.1).
  • The stale alert's title says what is wrong and its text says how old and what to do; the warning icon is aria-hidden.
  • The source link adds "(opens in a new tab)" in visually hidden text.
