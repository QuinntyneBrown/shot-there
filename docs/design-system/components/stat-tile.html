Stat tile

Stat tiles open the admin dashboard: one tile each for studios, spots and guides, with how many are published and how many are drafts, a link to the list and a button to start a new one.

Overview

The dashboard is the first screen the admin sees after signing in. It answers two questions: how much is live, and what can I add next (L2-053). The three tiles sit in a .stat-grid above the re-verification list, which uses admin rows.

  • Use a stat tile for the count of one content type on the admin dashboard, with a way into its list and a way to create one.
  • Don't use it on public pages. Visitors compare locations with location cards, scores and the comparison table, not with counts.
  • Don't turn it into a KPI card. There are no trends, deltas, sparklines or percentages: the admin publishes a handful of locations, and the numbers are exact counts.
  • Lists of individual studios, spots or guides belong on the admin list screens, which use the stacked table.

Anatomy

  1. Title link<h3 class="stat-tile__title"> wrapping a link to the admin list ("Studios"). --text-h4 in --color-fg-default, underlined.
  2. Counts.stat-tile__counts: "7 published, 2 draft", --text-body-lg, --color-fg-muted, tabular figures.
  3. ActionA button-styled link to the editor ("New studio") with a leading plus icon. Pinned to the bottom with margin-top: auto, so actions line up across a row.
  4. ContainerThe <li> itself: 1px --color-border-default, --radius-lg, padding --space-5 × --space-6, --space-3 between parts, no fill.

Variants

There is one tile. What varies is the emphasis of its action, and that is decided by the dashboard, not by the tile: the screen has one primary action.

Sizes

One size. The tile fills its grid cell (height: 100%) so tiles in a row match the tallest one; the grid decides the width (see Responsive behaviour).

States

The tile itself is not interactive; its title link and its action are. Pointer and focus states are forced with data-state here; real pages get them from :hover, :focus-visible and :active. Loading uses aria-busy="true" on the dashboard wrapper.

Dashboard states around the tiles

  • Loading (loading): each tile keeps its border and shows a title bar, a counts line and a pill where the button goes. The wrapper carries aria-busy="true" and a visually hidden role="status" "Loading the dashboard".
  • Zero counts (empty): tiles stay and say "0 published, 0 draft"; the empty state below carries the primary action.
  • Error (error): if the counts cannot load, the tiles are not drawn at all. An error empty state ("We couldn't load the dashboard", "Try again") replaces them; a tile never shows a guessed or zero count.
  • Partial (partial): the counts loaded but the re-verification list did not. Tiles render normally; the danger alert sits in the list's place and says "The counts above are current".
  • Up to date (up-to-date): tiles render normally; the list is replaced by a compact success empty state.

Responsive behaviour

  • Below 48rem the grid is one column and the tiles stack Studios, Spots, Guides (L2-053.3). From 48rem it is three equal columns.
  • The gap is --layout-gutter, so it widens with the page: 24px on phones, 32px from 48rem, 40px from 62rem.
  • The action keeps its natural width at every size (align-self: flex-start); it does not become full width on phones, because the tile is already a full-width target region and the button is 44px tall.
  • Counts wrap rather than truncate; "0 published, 0 draft" fits a 288px-wide tile with room to spare.
  • Respect device safe areas through the page container; the tile adds no fixed positioning of its own.

Theming

The tile has no fill: it reads --color-bg-canvas through the page, draws its edge in --color-border-default and its counts in --color-fg-muted. The title link is held at --color-fg-default rather than the link colour so the three tiles read as headings first. In dark, the canvas, border and text roles swap together, and the primary button flips to light stone with dark text, so the one primary still stands out.

/* The tile reads roles only; re-theme by overriding the roles in scope. */
.stat-tile { border-color: var(--color-border-default); }
.stat-tile__counts { color: var(--color-fg-muted); }

Accessibility

Role and pattern

Native structure, no ARIA widget: a <ul class="stat-grid"> of <li class="stat-tile">, so screen readers announce "list, 3 items". The section has a visually hidden <h2>Content</h2>, and each tile title is an <h3> wrapping a link, so heading navigation lands on Studios, Spots and Guides. The action is an <a> styled as a button because it navigates to the editor.

Keyboard

KeyAction
Tab / Shift+TabMoves through each tile's title link, then its action: Studios, New studio, Spots, New spot, Guides, New guide.
EnterFollows the focused link: the title opens the admin list, the action opens a new editor.

Focus

Both links show the shared ring (2px --color-focus-ring, offset) on :focus-visible. The tile has no focus of its own; it is never a single click target, so it never wraps its links in a bigger link.

Labelling

The heading text is the link name ("Studios"). The action names its object ("New studio"), so it makes sense out of context in a links list. Counts are plain text read after the heading; no aria-label rewrites them. While loading, skeleton spans are empty and the status message carries the meaning.

The tile border (--color-border-default) is decorative: it groups content but marks no control, so it is exempt from 1.4.11.

Motion

Only the skeleton shimmer moves, and it stops under prefers-reduced-motion. The button's hover transition reads --duration-fast, which reduced motion zeroes.

Touch

The action is a 44px button and the title link is --text-h4 type with the tile's padding around it. Title and action are at least --space-3 apart in every state, so a thumb never hits both.

Content

  • Title: the plural content type, as the admin navigation names it: "Studios", "Spots", "Guides".
  • Counts: exactly "{n} published, {m} draft" (L2-053.1): published first, a comma, and "draft" unchanged at any count. Zero is written as "0", never hidden or spelled out.
  • Action: "New" plus the singular type: "New studio", "New spot", "New guide", with the plus icon before it.
  • No other copy in the tile: no help text, no dates, no "last updated". What needs attention goes in the re-verification list below.
