Divider

A divider is a 1px hairline that separates two groups of content. No ShotThere mock uses one: screens separate content with white space and with the hairlines built into lists, tables, sheets and card footers. The divider stays as a core component for the rare case those don't cover.

Overview

Reach for space first. ShotThere pages are built from generous gaps (.section-gap between home sections, --space-16 between review sections), and every repeating structure already draws its own rule:

  • List rows: .section-list (the site menu, dashboard sections) and .admin-list draw a hairline above the list and below each row.
  • Tables: every row has a bottom hairline; .table-wrap adds one on top.
  • Sheets: a hairline under the header and over the footer. Cards: .card__footer has a hairline above its actions.
  • Inline metadata ("Junction · Dundas St W at Pacific Ave · Reviewed 29 Sep 2026") uses middots, drawn by .review-head__meta with empty alternative text, not vertical dividers.

Use <hr> only for a thematic break inside free content that none of these cover, such as a long editorial page that changes subject without a heading. Use a heading instead whenever the next part has a name.

Anatomy

  1. RuleA 1px top border in --color-border-default; border: 0 removes the browser's bevel.
  2. Space--space-6 above and below, so the rule sits in the gap rather than closing it.

Vertical

.divider--vertical stretches to the row's height (at least one icon tall) with --space-3 either side. It is not displayed below 36rem, where rows wrap and a vertical rule would dangle. Give it role="separator" with aria-orientation="vertical", or aria-hidden="true" when the gap alone separates.

.divider--label: two hairlines around a short muted label in --text-body-sm. Prefer a real heading; a labelled divider suits a break inside one list where a heading would be too loud.

Sizes

One thickness (--border-width-hairline, 1px) and one spacing: --space-6 above and below a horizontal divider, --space-3 either side of a vertical one. Change the spacing by changing the layout around it (a .stack gap), not the divider.

States

Not applicable: a divider is not interactive and has no states. Both themes are shown under Theming.

Responsive behaviour

  • Horizontal dividers span their container at every width.
  • Vertical dividers are not displayed below 36rem (display: none), because the row they sit in wraps on phones.
  • Labelled dividers keep the label on one line; the rules shrink around it. Keep labels to two or three words so they fit at 320px.

Theming

Every variant reads --color-border-default (and the label --color-fg-muted). Dark redefines the border as --palette-stone-750, a quiet line on the dark canvas. In forced colours borders take the system text colour automatically.

Accessibility

Role and pattern

Native <hr> has the implicit separator role, so a thematic break is announced. A .divider on another element takes role="separator" (with aria-orientation="vertical" when vertical) if the break matters, or aria-hidden="true" if it is only visual. Hairlines built into lists and tables are CSS borders and are not announced (WAI-ARIA separator role).

Keyboard

KeyAction
NoneA static separator is not focusable. (A focusable separator is a window splitter; ShotThere has none.)

Focus

Never receives focus.

Labelling

A labelled divider's text is its name. Plain dividers need no name.

Contrast

Divider label on page
Divider label in a dialog or sheet

The rule itself is decorative and exempt from 1.4.11 (non-text contrast): nothing depends on seeing it, because the space around it and the content on either side already separate the groups.

Motion

No motion.

Touch

Not a target. A vertical divider between two buttons adds --space-3 either side, which keeps the buttons' targets apart.

Content

  • Labels are two or three words in sentence case: "Older drafts". Not "OR", not all caps.
  • If you are tempted to write a sentence on a divider, it is a heading or a paragraph.
  • For inline facts use middots in text ("Studio · Prices verified 2 Mar 2026"), not vertical bars or dividers.
