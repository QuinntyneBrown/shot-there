Breadcrumb

A one-line trail above the page title that says where this page sits and links back to the list it came from: Studios, Spots or Guides.

WCAG 2.2 AAStatus: stableAPG Breadcrumb.breadcrumb .breadcrumb--collapse

Overview

Every detail page has one. On the public site it sits on studio, spot and guide pages and leads back to the list (Studios / The Junction Loft). In the admin it sits on the studio, spot and guide editors and leads back to the admin list (Studios / Corktown Garage Studio). It is the first thing in <main>, directly above the page title.

  • ShotThere's trails are two levels deep: a section list and the page itself. The wordmark already goes home, so the trail never starts with "Home".
  • Do not use it on list pages, the home page, the map or compare; those are top-level and the site header marks them with aria-current.
  • It is not a back button. It always names the same parent, wherever the visitor came from.

Anatomy

  1. Landmark<nav aria-label="Breadcrumb"> around an ordered list .breadcrumb; body-small type in --color-fg-muted.
  2. Parent linkThe section list. Muted, no underline until hover; at least 24px tall (44px on phones).
  3. SeparatorA "/" drawn by CSS before every crumb but the first, in --color-fg-subtle, with empty alternative text so it is never read.
  4. Current pagePlain text with aria-current="page", --color-fg-default at medium weight. Not a link.

Variants

One trail shape, four contents: the page's own name, a placeholder while the record loads, the parent alone when the record could not be opened, and a collapsed form for phones.

Sizes

The breadcrumb has one size: --text-body-sm, with links at least --target-min (24px) tall, growing to --target-comfortable (44px) below 48rem.

States

Only the parent link is interactive. Hover and focus are forced with data-state; the current crumb uses the real aria-current="page".

Responsive behaviour

  • The trail sits in the page container, so it takes the page margin (16px on phones) and never scrolls sideways.
  • The default trail wraps: each crumb is its own flex row, so a long name such as "Best studios under $120 for 2 hours" wraps with its separator beside it (breadcrumb D-7).
  • .breadcrumb--collapse keeps only the parent below 48rem, prefixed with "‹". Use it where the current name is long and the page title right below repeats it anyway.
  • Below 48rem the links grow to 44px tall (L2-065.1); from 48rem they are 24px, the WCAG 2.5.8 minimum.

Theming

The breadcrumb reads three text roles and nothing else: --color-fg-muted for the trail and its links, --color-fg-default for hover and the current page, --color-fg-subtle for separators. It has no background, so it sits on whatever the page uses (--color-bg-canvas in every mock). Both themes swap those roles; the component CSS does not change. In forced colours the links take LinkText and the separators CanvasText from the system, and the current page stays plain text.

Accessibility

Role and pattern

WAI-ARIA APG Breadcrumb: a <nav aria-label="Breadcrumb"> landmark around an <ol>, so screen readers announce "Breadcrumb navigation, list, 2 items". The last item carries aria-current="page" and is not a link. Separators are CSS generated content with empty alternative text (content: "/" / "", breadcrumb D-4), so they are not read as "slash".

Keyboard

KeyAction
Tab / Shift+TabMoves to and from the parent link. The current page is text and is skipped.
EnterFollows the link to the list.

Focus

The trail is the first thing in <main>, so after "Skip to content" (L2-067.1) the parent link is the first stop in the page body. It shows the shared ring: 2px --color-focus-ring with a 2px offset on :focus-visible.

Labelling

Use exactly aria-label="Breadcrumb" on the <nav>; "navigation" is added by the landmark. Link text is the section name ("Studios"), which makes sense on its own. While loading, the current crumb holds a visually hidden "Loading" beside an aria-hidden skeleton.

Breadcrumb links are not underlined until hover. That is the one exception to the underlined-link rule: the landmark, the position above the title and the separators identify them as links, and the hover underline confirms it.

Motion

Nothing animates except the loading skeleton's shimmer, which stops under prefers-reduced-motion.

Touch

The parent link is 44px tall below 48rem and 24px from 48rem up; it is the only target in the trail, so there is no neighbouring target to mis-tap.

Content

  • The parent is the section's name as the site header says it: "Studios", "Spots", "Guides". In the admin the same words lead to the admin lists.
  • The current crumb is the record's name exactly as the page title shows it: "The Junction Loft", "Evergreen Brick Works", "Best studios under $120 for 2 hours".
  • An unsaved record is "New studio", "New outdoor spot" or "New guide", matching the editor's title.
  • Never truncate a name with an ellipsis; let it wrap, or collapse the trail on phones.
